Product assumptions

先减少不确定性，再谈“更快挂上号”

这是一个个人信息雷达，不是抢号器。它负责整理公开规则、追踪变化、在可能值得核验时提醒；是否有号、是否满足预约条件、是否最终提交，全部以官方渠道当下页面为准。

  • 01
    首批范围固定。只服务北京同仁医院崇文门院区鼻科、北京协和医院皮肤科；全站数据均为演示。
  • 02
    协和只监测公开排班。仅表达 schedule_released 与排班变化，不显示实时有号、无号或退号结论。
  • 03
    稳定开源、本地运行。无 Docker、无云端、无遥测；SQLite 单进程，只保存提醒所需最少信息。
  • 04
    终点是官方渠道。同仁鼻科默认做 C 级规则提醒并提供官方候补入口；所有预约仍由用户手动核验并提交。

Trust model

为什么三个方向共享同一信任模型：评审应比较信息架构与心理感受，而不是让视觉差异稀释医疗数据边界。A / B / C 表示合规接入方式，不表示数据“好坏”。

A无需登录的官方公开页面 / 接口
监测公开排班变化
B本机浏览器已有会话
仅向 127.0.0.1 返回脱敏状态
C小程序 / 不可合规读取
只做规则提醒，不逆向
设计取舍：A 把“可审计”放在首位；B 把“降低焦虑、下一步清楚”放在首位；C 把“单位屏幕的信息与变化密度”放在首位。三者均避免营销页结构、装饰卡片和虚构成功率。

切换评审方向

不是换肤：导航语言、首页任务模型、密度与解释方式都会变化。

当前 B · 温暖克制的个人健康助理
产品边界：只提醒，不代预约，不自动提交。 公开数据可能延迟、缺失或变化；所有预约信息必须在官方渠道重新核验。

Manual completion boundary

打开官方渠道，手动完成预约

雷达只把你带到“值得核验”的时刻。进入官方渠道后，请重新确认医院、院区、科室、医生、日期、费用与就诊人资格。

  1. 离开雷达
    不传递身份证、医保卡或登录凭证。
  2. 在官方页面重新核验
    演示信号不是可预约承诺。
  3. 由你手动选择并提交
    雷达不会自动点击、占号或抢号。
评审环境不会跳转到任何未核验链接。稳定本地版只提供经过核验的医院官网、官方公众号或北京市预约挂号平台入口，不代理登录或提交。
